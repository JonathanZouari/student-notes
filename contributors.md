## How to Become a Contributor

1. Fork the repository.
2. Create a branch for your change: `git checkout -b feature/your-change`
3. Add or improve notes, following the existing structure and formatting.
4. Commit your changes with a clear message.
5. Open a Pull Request describing what you added or fixed.

Once your PR is merged, add yourself to the table above (or ask a maintainer to).

## Guidelines

- Keep notes clear, accurate, and well-organized.
- Cite sources where relevant.
- Be respectful and constructive in reviews and discussions.

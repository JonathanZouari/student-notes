# Contributors תורמי הפרויקט

## English

### Who are the contributors?

Contributors are everyone who helped build **student-notes**: writing and editing notes, reviewing changes, organizing the repository, and keeping the project running.

| Name | Role | Short Description |
|------|------|-------------------|
| Noa Levi | Project Lead | Coordinates the team, sets goals, and approves the final merge of Pull Requests. |
| Daniel Cohen | Repository Maintainer | Manages branches, repository settings, and keeps the main branch stable. |
| Maya Friedman | Content Writer | Writes and updates course summaries and lecture notes. |
| Yonatan Mizrahi | Code Reviewer | Reviews Pull Requests and gives feedback before changes are merged. |
| Shira Avraham | Documentation Editor | Maintains the README and other guides, and keeps writing consistent. |
| Itay Peretz | Issue Manager | Opens, labels, and tracks Issues, and assigns tasks to team members. |
| Tamar Ben-David | Design & Formatting | Handles Markdown formatting, tables, and images so notes are clear and readable. |

### How to Join

1. **Fork** – Click **Fork** at the top of the repository page to create your own copy.
2. **Branch** – Create a new branch for your change:
```bash
   git checkout -b feature/add-my-notes
```
3. **Make a change** – Edit or add files, then stage only the files you changed, commit and push:
```bash
   git add notes/lecture-3.md
   git commit -m "Add notes for lecture 3"
   git push origin feature/add-my-notes
```
4. **Pull Request** – Open a Pull Request to the original repository and describe what you changed.

> You can also do all of these steps directly on the GitHub website, without the command line.

### איך להצטרף

1. **Fork** – לחצו על **Fork** בראש עמוד המאגר כדי ליצור עותק משלכם.
2. **Branch** – צרו ענף חדש עבור השינוי שלכם:
```bash
   git checkout -b feature/add-my-notes
```
3. **שינוי** – ערכו או הוסיפו קבצים, הוסיפו ל-Staging רק את הקבצים ששיניתם, ואז בצעו commit ו-push:
```bash
   git add notes/lecture-3.md
   git commit -m "Add notes for lecture 3"
   git push origin feature/add-my-notes
```
4. **Pull Request** – פתחו Pull Request למאגר המקורי ותארו מה שיניתם.

> אפשר לבצע את כל השלבים האלה גם ישירות באתר GitHub, בלי שורת פקודה.

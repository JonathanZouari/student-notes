## How to Join?

1. **Fork:** Open the [original repository](https://github.com/JonathanZouari/student-notes) and click **Fork** to create your own copy.

2. **Clone:** Copy your fork's clone URL from GitHub and run:
   ```bash
   git clone <your-fork-url>
   ```

3. **Enter the folder:** Use `cd` followed by the folder name created by Clone.

4. **Create a branch:**
   ```bash
   git switch -c feature/my-change
   ```

5. **Make your changes:** Edit or add files, inspect the changes with `git status`, then stage the files you intend to include:
   ```bash
   git add <file-name>
   ```

6. **Commit:** Save the staged changes with a clear message:
   ```bash
   git commit -m "docs: describe your change"
   ```

7. **Push:** Upload your branch to your fork:
   ```bash
   git push -u origin feature/my-change
   ```

8. **Open a Pull Request:** On GitHub, open your fork and click **Compare & pull request**. Confirm that the destination is the original repository. Describe what changed, why, and how to check it, then submit for review.

Thank you for helping improve the project!

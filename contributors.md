## 🚀 How to Contribute
1. **Fork** this repository to your own GitHub account.
2. **Create a branch** for your work:
   `git checkout -b feature/your-feature-name`
3. **Make your changes** and check that everything works as expected.
4. **Commit** your changes with a clear message:
   `git commit -m "feat: short description of your change"`
5. **Push** your branch to your fork:
   `git push origin feature/your-feature-name`
6. **Open a Pull Request** to the original repository, explaining what you changed and why.

We review every Pull Request and appreciate every contribution, big or small. Happy coding! 🎉

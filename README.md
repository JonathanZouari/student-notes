# student-notes
אפליקציית ניהול הערות לסטודנטים

סיכומים ושיחות לסטודנטים. דורשת Python 3 בלבד, בלי התקנות נוספות.

```bash
python3 server.py
```
ואז לפתוח http://localhost:8000

## מה יש
- **ספרייה אישית לכל סטודנט**: מסודרת לפי שנים, ובכל שנה הקורסים שהסטודנט רשום אליהם.
  בכל קורס: סיכומים שהסטודנט כותב (עם שמירה אוטומטית) וקבצים שהוא מעלה (עד 15MB לקובץ).
  רק הסטודנט עצמו רואה את הסיכומים והקבצים שלו.
- **צ'אט עם המרצה**: שיחה פרטית בין כל סטודנט למרצה של הקורס. המרצה רואה רשימה של כל הסטודנטים בקורס ופותח שיחה עם כל אחד.
- **צ'אט הקורס**: קבוצה משותפת לכל הסטודנטים הרשומים לקורס.
- **מסך ניהול** (משתמש מנהל): הוספה, עריכה ומחיקה של שנים, קורסים (כולל שיוך שנה ומרצה) ומשתמשים, איפוס סיסמאות,
  ורישום סטודנטים לקורסים בסימון V. הסרת סטודנט מקורס לא מוחקת את הסיכומים שלו – הם יחזרו אם יירשם שוב.

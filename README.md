## כיצד להצטרף?

אנחנו שמחים על כל תרומה — קטנה כגדולה, מתיקון שגיאת כתיב ועד פיצ'ר חדש. כך מתחילים:

1. **עשו Fork** לריפוזיטורי לחשבון ה-GitHub שלכם.
2. **שכפלו** את הפרויקט למחשב שלכם:
   ```bash
   git clone https://github.com/YOUR_USERNAME/student-notes.git
   cd student-notes
   ```
3. **צרו Branch חדש** עם שם שמתאר את השינוי:
   ```bash
   git checkout -b feature/short-description
   ```
4. **בצעו את השינויים** ובדקו שהכול עובד כמצופה.
5. **בצעו Commit** עם הודעה ברורה:
   ```bash
   git commit -m "Add: short description of the change"
   ```
6. **דחפו (Push)** את ה-Branch לריפוזיטורי שלכם:
   ```bash
   git push origin feature/short-description
   ```
7. **פתחו Pull Request** ל-Branch הראשי, ותארו מה שיניתם ולמה.

# student-notes

אפליקציית ניהול הערות לסטודנטים: מקום אחד לכתוב, לשתף ולשפר הערות מהקורסים.

## על הפרויקט

ששש
Student Notes עוזרת לסטודנטים לשמור את ההערות שלהם מהשיעורים ולשתף אותן עם חברים לקורס.
כל משתמש יכול להעלות הערות חדשות ולהציע תיקונים להערות של אחרים, כך שהתוכן משתפר עם הזמן.

> **סטטוס:** הפרויקט בשלב תכנון. יש מסמכי רעיון ואב-טיפוס של לוח הניקוד.

## לוח הניקוד (אב-טיפוס)

אפליקציית ווב שמציגה את הניקוד של המשתמשים לפי [חוקי הניקוד](docs/points-feature.md):

- לוח מובילים שבועי וכללי.
- פרופיל לכל משתמש עם נקודות, רמה, התקדמות לרמה הבאה והיסטוריה.
- כפתורים שמדמים העלאת הערה או תיקון, כדי לראות את החוקים בפעולה (כולל התקרה היומית).

**איך פותחים:** פותחים את הקובץ `app/index.html` בדפדפן. לא צריך להתקין כלום.
**בדיקות:** פותחים את `app/tests.html` בדפדפן.

הנתונים באב-טיפוס הם נתוני דוגמה, ושינויים נשמרים רק עד רענון העמוד.

| קובץ | תפקיד |
|---|---|
| `app/points.js` | חוקי הניקוד (חישוב נקודות, תקרה יומית, רמות, לוח מובילים) |
| `app/data.js` | נתוני דוגמה |
| `app/app.js` | הממשק |
| `app/tests.html` | בדיקות לחוקי הניקוד |

## פיצ'רים עיקריים (מתוכננים)

- **הערות:** יצירה, עריכה ומחיקה של הערות לפי קורס.
- **שיתוף:** צפייה בהערות של סטודנטים אחרים באותו קורס.
- **תיקונים:** הצעת תיקון להערה של משתמש אחר, ואישור התיקון על ידי בעל ההערה.
- **ניקוד:** נקודות על כל הערה ותיקון, עם רמות ולוח מובילים. הפירוט ב[מסמך הניקוד](docs/points-feature.md).
